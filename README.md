## How to import into Notion
1. In Notion, create a new page → type `/database` → **Table – Full page**
2. Click the `···` menu → **Merge with CSV** → select `meal-plan.csv`
3. Change the view to **Calendar** and group by `Date`
4. Add filter/sort by `Meal Type` for cleaner daily view
